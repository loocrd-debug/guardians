==========================================
 가디언즈 웹 품질 검사 v6.20 — 실행 안내
==========================================

[설치 프로그램으로 설치한 경우]
  바탕화면의 "가디언즈 웹 품질 검사" 아이콘을 더블클릭하면 됩니다.
  잠시 후 브라우저가 자동으로 열립니다. (http://localhost:3000)
  검사용 브라우저가 포함되어 있어 인터넷 없이도 접근성·KRDS·보안 검사가 됩니다.
  (오탈자·HTML 표준·외부 링크 검사는 인터넷이 필요합니다)

[ZIP으로 받은 경우]
  1. ZIP 우클릭 > 속성 > [차단 해제] 체크 > 확인   (이 단계가 없으면 START.bat이 바로 닫힙니다)
  2. 압축 풀기
  3. START.bat 더블클릭

[스크린 리더 시뮬레이션 (v6.19 신규)]
  메뉴 "스크린 리더" → 주소 + 기기(iPhone/Galaxy/데스크톱) → 낭독기가 읽는 순서·이름을 대본으로 보고,
  ▶ 버튼으로 Windows 내장 한국어 음성으로 듣습니다(인터넷 불필요). 줄을 누르면 캡처에서 그 요소가 강조됩니다.

[KRDS 기준 자동 수신 (v6.20 신규)]
  인터넷이 연결되면 실행 1분 뒤 · 12시간마다 guardians.ai.kr에서 담당자가 승인 · 발행한 최신 KRDS 기준을 받아
  전자서명을 확인한 뒤 적용합니다(서명이 맞지 않으면 적용하지 않음). 행정망에서는 더보기 › KRDS 기준 추적 ›
  [기준 파일 가져오기]로 적용합니다. 결과에는 적용한 기준 버전(예: KRDS 기준 2026.10.0)이 기록됩니다.

[AI 보조 (선택)]
  화면 오른쪽 위 "AI" → 개인 Claude API 키 입력 → 저장. (키는 이 PC의 data\settings.json 에만 저장)
  켜지면: 말로 지시하기(1단계) · AI로 빈칸 채우기(위반 항목) · AI 요약·전달문(결과)
  AI는 검사 결과를 바꾸지 않습니다. 키가 없거나 폐쇄망이면 자동으로 숨겨집니다.

[인터넷 배포(웹 서비스)]
  같은 소스를 서버에 올리면 설치 없이 주소로 쓰는 웹 서비스가 됩니다.
  deploy\README-인터넷배포.md 참고 (Docker · 접근 비밀번호 · 내부망 주소 차단 · AI 키 서버 미저장)

[폐쇄망(행정망) 사용]
  인터넷 없이도 설치·실행·검사가 됩니다. 접근성·KRDS·보안 검사는 온라인과 동일하고,
  오탈자·HTML 표준은 내장 엔진으로 자동 전환되며, 외부 링크는 "확인 불가"로 표시됩니다.
  화면 오른쪽 위에 "인터넷 연결 / 폐쇄망 모드"가 표시됩니다.

[Windows 시작 시 자동 실행]
  설치 중 체크했다면 로그인 시 창 없이 조용히 실행됩니다. (예약 검사에 필요)
  직접 설정: "start-hidden.vbs"의 바로가기를 shell:startup 폴더에 넣으세요.

[Chrome 확장 프로그램]
  시작 메뉴 > 가디언즈 > "Chrome 확장 설치 도우미" 를 실행하면
  확장 페이지와 폴더가 열립니다. 개발자 모드 켜기 > extension 폴더 끌어놓기 두 단계면 끝.
  (브라우저 보안 정책상 웹 스토어 밖 확장은 이 두 단계를 사람이 해야 합니다)

[종료]
  실행 창에서 Ctrl+C  또는  STOP.bat

[SmartScreen 경고가 뜰 때]
  "Windows의 PC 보호" 창 → "추가 정보" → "실행" 을 누르세요.
  (코드 서명 인증서가 없는 설치 파일에 나타나는 일반적인 안내입니다)

[접속 주소]
  메인      http://localhost:3000
  예약 검사  http://localhost:3000/schedule.html
  검사 기준  http://localhost:3000/criteria.html
