==========================================
 가디언즈 빠른 접근성 검사 — Chrome 확장 설치
==========================================

[설치 (30초)]
  1. Chrome 주소창에  chrome://extensions  입력
  2. 오른쪽 위 "개발자 모드" 켜기
  3. "압축해제된 확장 프로그램을 로드합니다" 클릭
  4. 이 폴더(extension)를 선택
  5. 주소창 오른쪽 퍼즐 아이콘 → "가디언즈" 고정(핀)

  Edge도 같습니다: edge://extensions → 개발자 모드 → 압축 해제된 확장 로드

[사용]
  아무 웹페이지에서 툴바의 가디언즈 아이콘 클릭 → "이 페이지 검사"
  · 몇 초 안에 접근성 점수·위반 목록(KWCAG 2.2 조항)이 나옵니다
  · "위반 요소 표시" → 페이지 위에 위반 위치가 테두리로 표시됩니다
  · "가디언즈에서 정밀 검사" → 설치된 가디언즈 도구가 열리며 주소가 자동 입력됩니다
     (오탈자·링크·KRDS·보안·스크린샷·PPTX 결과서는 도구에서)

[전체 규칙 / 핵심 15]
  전체 규칙 = WCAG 2.1 AA 전체 (권장) · 핵심 15 = 자주 틀리는 15개만 (빠름)

[안 되는 곳]
  chrome:// 내부 페이지, PDF, 웹 스토어, 일부 보안 정책(CSP)이 강한 사이트

[Chrome 웹 스토어]
  해커톤 이후 스토어 등록 시 "개발자 모드" 없이 설치할 수 있습니다.
==========================================

[v6.19 사이드 패널]
  도구 아이콘을 누르면 팝업 대신 브라우저 오른쪽에 패널이 열립니다. 탭을 바꿔도 패널이 유지되고,
  "자동 검사"를 켜면 페이지가 바뀔 때마다 다시 검사합니다. 설정(톱니)에서 정밀 검사 서버 주소를 바꿀 수 있습니다
  (설치형: http://localhost:3000, 팀 웹: https://guardians.ai.kr).
  권한 안내에 "모든 사이트의 데이터 읽기"가 뜨는 것은 패널이 현재 탭을 검사해야 하기 때문입니다.

[v6.19] 사이드 패널에서 접근성 · KRDS(정밀 판정 16규칙 + 디자인 토큰 11항목) · 웹표준 간이 점검을 한 번에 검사합니다.
  정밀 검사 버튼은 기본으로 팀 웹(https://guardians.ai.kr)으로 연결되며, 설정(톱니)에서 설치형으로 바꿀 수 있습니다.
