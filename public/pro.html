WCAG 접근성 W3C WCAG 2.1 국제 표준 기반

웹 콘텐츠 접근성 지침(WCAG 2.1)은 W3C가 제정한 국제 표준으로, 장애가 있는 사용자도 웹을 동등하게 이용할 수 있도록 보장합니다.

  • 검사 엔진: axe-core v4 (Deque Systems 개발, 업계 표준 오픈소스)
  • 준수 수준: Level A (최소) / Level AA (권장·법적 기준) / Level AAA (최고)
  • 주요 항목: 이미지 대체텍스트, 키보드 접근성, 색상 대비, 폼 레이블, 제목 구조, 동영상 자막 등 50여 개 규칙 자동 검사
  • 검사 방식: Chromium 브라우저로 페이지를 완전 렌더링 후 DOM 분석
→ W3C WCAG 2.1 공식 문서   → axe-core 공식 사이트
링크 검사 HTTP 상태코드 기반 데드링크 탐지

페이지 내 모든 <a href> 링크를 추출하여 실제 요청을 보내 응답 상태를 확인합니다.

  • 데드링크: 404 Not Found, 410 Gone, 500 Server Error 등 오류 응답
  • 리다이렉트: 301/302 영구·임시 이동 여부 확인
  • W3C Link Checker 옵션: W3C 공식 Link Checker API(validator.w3.org/checklink)를 추가 연동하여 더 정밀한 검사 수행
  • 제외 항목: javascript:, mailto:, tel: 등 비HTTP 링크
→ W3C Link Checker 공식 페이지
오탈자 검사 Daum 맞춤법 검사기 API 기반

페이지의 텍스트 콘텐츠를 추출하여 Daum 맞춤법 검사기 API에 전송, 한국어 오탈자·맞춤법 오류를 검출합니다.

  • 검사 API: Daum 맞춤법 검사기 (dic.daum.net) — 국내 최대 규모 한국어 사전 기반
  • 검출 항목: 철자 오류, 띄어쓰기, 문장 부호, 표준어 오류
  • 오프라인 폴백: Daum 서버 연결 실패 시 내장 패턴(되요→돼요 등 20여 개)으로 자동 전환
  • 제한: 전문 용어·고유명사·약어 등은 오탐(False Positive) 가능
W3C 마크업 W3C HTML Validator 공식 API 연동

W3C 공식 마크업 검증 서비스(validator.w3.org)에 페이지 HTML을 전송하여 HTML5 표준 준수 여부를 검사합니다.

  • 검사 기준: HTML5 (W3C Recommendation) 명세 준수 여부
  • 검출 항목: 잘못된 태그 중첩, 필수 속성 누락, 폐기된 요소 사용, 문서 구조 오류
  • 오류 등급: Error(반드시 수정) / Warning(권장 수정)으로 구분
  • 검사 서버: validator.w3.org (W3C 공식 서버, 외부 인터넷 연결 필요)
→ W3C Markup Validation Service
KRDS 검사 한국 디지털 서비스 표준 (행정안전부)

행정안전부가 고시한 한국 디지털 서비스 표준(KRDS)에 따라 전자정부 웹사이트의 UI·UX 준수 여부를 자동으로 검사합니다.

  • 검사 기준: 행정안전부 KRDS 가이드라인 (krds.e-gov.go.kr)
  • 자동 검사 항목 (24개): lang 속성, title 태그, viewport, 건너뛰기 링크, 공식 전자정부 배너, header/footer/main 구조, h1 태그, 이미지 alt, 폼 레이블, 개인정보처리방침 링크, 저작권 표시 등
  • 검사 방식: Chromium으로 렌더링된 DOM을 JavaScript로 분석
  • 한계: 시각적 디자인·색상 대비·사용자 테스트가 필요한 항목은 자동화 불가 — 수동 검토 병행 권장
  • 규칙 커스터마이징: krds-rules.json 파일 수정으로 항목 추가·비활성화 가능
→ KRDS 공식 사이트 (행정안전부)
